# OpenDeviceStudio 0.2.0 rename migration

This release intentionally renames the project and its public identities from **UpperHost** to **OpenDeviceStudio**. It is a breaking migration and the package version moves from `0.1.0-alpha.1` to `0.2.0-alpha.1`.

## Required consumer changes

1. Replace NuGet/project identities `UpperHost.*` with `OpenDeviceStudio.*`.
2. Replace C# namespaces and using directives `UpperHost.*` with `OpenDeviceStudio.*`.
3. Replace configuration root `UpperHost:` with `OpenDeviceStudio:`.
4. Replace branded public APIs, including:
   - `UpperHostApplication` → `OpenDeviceStudioApplication`
   - `IUpperHostModule` → `IOpenDeviceStudioModule`
   - `UpperHostTelemetry` → `OpenDeviceStudioTelemetry`
   - `UpperHostTransportOptions` → `OpenDeviceStudioTransportOptions`
   - `AddUpperHost...` → `AddOpenDeviceStudio...`
5. Update source paths and commands:
   - `UpperHost.slnx` → `OpenDeviceStudio.slnx`
   - `src/UpperHost.*` → `src/OpenDeviceStudio.*`
   - `app/UpperHost.App` → `app/OpenDeviceStudio.App`
   - `samples/UpperHost.Sample.*` → `samples/OpenDeviceStudio.Sample.*`
   - `tests/UpperHost.Tests` → `tests/OpenDeviceStudio.Tests`

## Compatibility evidence

`eng/compatibility/package-renames.json` is the machine-readable one-to-one package rename contract. PR #80 must change both that contract and this migration document. The compatibility gate still uses the exact-base package artifact; it recognizes the legacy artifact only to validate this migration and does not silently fall back to stale baselines.
